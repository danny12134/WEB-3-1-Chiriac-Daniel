Partea 1 - România

România este o țară situată în sud-estul Europei, la granița cu Ungaria, Serbia, Bulgaria, Republica Moldova și Ucraina. Capitala țării este București. România este cunoscută pentru munții Carpați, Delta Dunării și castelele din Transilvania.

Obiective turistice:

  • Castelul Peleș
  • Delta Dunării
  • Cetatea Râșnov
  • Mănăstirea Voroneț
  • Salina Turda

Partea 2 - Franța

Franța este o țară din Europa de Vest, cu ieșire la Oceanul Atlantic și la Marea Mediterană. Capitala sa este Paris. Franța este cunoscută pentru arta, gastronomia și monumentele sale istorice.

Activități pentru turiști:

  1. Vizitarea Turnului Eiffel
  2. Plimbare pe Coasta de Azur
  3. Tur al castelelor din Valea Loarei
  4. Vizitarea Muzeului Louvre
  5. Degustarea vinurilor din Bordeaux

Partea 3 - Italia

Italia este o țară din sudul Europei, situată pe Peninsula Italică. Capitala este Roma. Italia este cunoscută pentru istorie, arhitectură, gastronomie și industria modei.

Termeni asociați Italiei:

Roma
Capitala Italiei, cunoscută pentru Colosseum și Vatican.
Pizza
Preparat tradițional italian, originar din orașul Napoli.
Ferrari
Producător italian celebru de automobile sportive.
Veneția
Oraș construit pe apă, cu canale și gondole.
